## Info

This repo is forked from [notablog-starter](https://github.com/dragonman225/notablog-starter) and I use it to deploy my personal blog. Thanks to [@dragonman225](https://github.com/dragonman225).

### Principle

By setting GitHub workflow config files, CI will fetch data from Notion and transfer those data to html.

It will trigger once you push new commits to this repository or run every hour. You can edit config file according to the [GitHub Docs](https://docs.github.com/en/actions) to fit your needs.
